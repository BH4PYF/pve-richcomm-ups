# 运维手册

## 1. 日常检查

```bash
# 一眼看状态
upsc ups

# 五个服务都应该 active
systemctl is-active ups-poller ups-nut-bridge nut-server ups-net-watch ups-dingtalk

# 原厂程序必须是 disabled，且不能和 poller 同时跑
systemctl is-enabled ups-manager
pgrep -af ups_monitor || true

# USB 在不在
lsusb | grep 0925:1234
```

正常输出：

```
ups.status: OL TRIM
input.voltage: 223.0
ups.load: 22
battery.voltage: 25.60
battery.charge: 99
battery.runtime: 2970
ups.delay.shutdown: 3600
```

## 2. 服务地图

| 服务 | 作用 | 依赖 |
|---|---|---|
| `ups-poller` | 独占 USB，产 `state.json`，管关机计时 | 无（需 libusb） |
| `ups-nut-bridge` | `state.json` → NUT，SOC/续航，网页 JSONP | poller |
| `nut-driver@ups` | `dummy-ups` 读 `ups.dev` | bridge |
| `nut-server` | `upsd` 监听 3493 | driver |
| `ups-linkcheck.timer` | 每 2 分钟体检 | poller |
| `ups-net-watch` | UPS 状态与网卡 link 相关性日志 | poller |
| `ups-usbmon` | usbmon 抓包，保留 USB 层证据 | debugfs |
| `ups-dingtalk` | 钉钉告警 | upsd |
| `ups-manager` | 原厂 32 位程序，**保持 disabled** | 与 poller 冲突 |

## 3. 常用操作

### 3.1 改配置

```bash
sudo cp /etc/ups-pve/runtime.conf /root/runtime.conf.bak.$(date +%s)
sudo editor /etc/ups-pve/runtime.conf
watch -n2 'upsc ups battery.runtime battery.charge'
# 约 10 秒生效；要刷新 ups.delay.shutdown 则：
sudo systemctl restart ups-nut-bridge
```

### 3.2 改关机延时

`TimeCfg.conf` 是二进制，不要用文本编辑器。当前 F=3600、L=30 对应：

```
35 03 aa 55 10 0e 00 00 1e 00 00 00 b4 00 00 00 0a 00 00 00
```

即偏移 4 的 int32 LE = 3600，偏移 8 = 30。改完 poller 自动重读；桥接缓存需要重启。

### 3.3 深度自检（放电）

```bash
# 先确认市电正常、负载低、有人值守
upsc ups ups.status ups.load

# 停 poller，发 TL，再恢复
sudo ups-selftest deep

# 另一终端监控，最多 2 小时，放到 22.2 V 主动 CT
sudo ups-selftest-watch --min-pack 22.2 --max-runtime 7200

# 兜底：到点无条件 CT
sudo ups-selftest-guard 7200
```

规则：

- 电池供电时**绝不**在没有 watcher 的情况下发 `TL`。
- `--max-runtime` 必须大于计划时长（默认 1500 s 只够 25 分钟）。
- 测试前临时放大 `TimeCfg` 的 F/L，测后恢复并核对。
- 测试后确认 `upsc` 回到 `OL`，`self_test` 为 Normal。

### 3.4 取消自检

```bash
sudo ups-selftest cancel
# 或等 ups-autoct 在设备重连后补发
```

### 3.5 设备掉线

```bash
# 看 poller 日志
journalctl -u ups-poller -n 50 --no-pager

# 看 USB 层
lsusb -t | grep -A2 0925
dmesg | tail -30

# 手动重启
sudo systemctl restart ups-poller
```

poller 自己会在 `LIBUSB_ERROR_NO_DEVICE` 后每 2 s 重开；udev `add` 规则会再重启一次，保证新 devnum。

### 3.6 网页卡片不见了

```bash
sudo /usr/local/lib/ups-pve/patch-pve-gui.sh
systemctl try-restart pveproxy
curl -s http://127.0.0.1:8006/ | grep pve-ups-status
```

pve-manager 升级会替换 `index.html.tpl`；APT 钩子 `99pve-ups-gui` 正常情况下会自动补。

### 3.7 钉钉不发了

```bash
systemctl status ups-dingtalk
journalctl -u ups-dingtalk -n 50 --no-pager
sudo ls -l /etc/ups-dingtalk/dingtalk.env   # 必须是 600
# 测试发送
sudo python3 /usr/local/lib/ups-pve/dingtalk_monitor.py --test
```

不打印 webhook/token；只看服务日志里的错误码。

### 3.8 临时回退原厂程序

```bash
sudo systemctl disable --now ups-poller ups-nut-bridge
sudo systemctl enable --now ups-manager
# fix-hiddev 会由 ups-manager 的 ExecStartPre 处理
```

回退前确认 NAS 不会因为 NUT 消失而误关机。

## 4. 日志位置

| 路径 | 内容 |
|---|---|
| `journalctl -u ups-poller` | 打开、掉线、Q1、bits 变化、关机计时 |
| `journalctl -u ups-nut-bridge` | NUT 变量、SOC、告警、FSD |
| `/var/log/ups-incidents/<时间戳>.log` | 每 2 分钟体检的异常现场（dmesg、lsusb、journal 片段） |
| `/var/log/usbmon-ups.log` | usbmon 抓包（需 `ups-usbmon.service`） |
| `/var/log/ups-selftest-watch.log` | 放电监控决策 |
| `/var/log/ups-discharge.csv` | 10 s 放电数据（手动启动） |
| `/var/log/ups-net-correlate.csv` | 15 s UPS/网卡相关性 |
| `/var/log/ups-soak.log` | 1 分钟 soak |
| `/run/ups-poller/state.json` | 当前状态（易失） |
| `/var/lib/ups-pve/battery.json` | SOC 持久状态 |

## 5. 常见故障

| 症状 | 可能原因 | 处理 |
|---|---|---|
| `upsc` 报 `Data stale` | bridge 停、`.dev` 没更新 | `systemctl status ups-nut-bridge`；重启 |
| `ups.status: ALARM` | poller 无有效帧 >5 s | 查 USB；`journalctl -u ups-poller` |
| 电压 0.0 但进程活着 | 原厂 hiddev 节点漂移（旧方案） | 本项目不走 hiddev；若回退原厂，跑 `fix-hiddev.sh` |
| `battery.runtime` 不更新 | 负载为 0 或 `RUNTIME_MINUTES=0` | 查 `runtime.conf` 与 `ups.load` |
| 断电后不关机 | `TimeCfg` 被改、poller 没读到、`shutdown.sh` 缺失 | 查 poller 日志的 "shutdown timer"；核对 `/opt/ups-manager` |
| 自检一直不结束 | 设备掉线导致 `CT` 没发 | `ups-autoct` 应在重连后补发；手动 `ups-selftest cancel` |
| 网页卡片空白 | 模板被升级替换 | 跑 `patch-pve-gui.sh`，重启 pveproxy |

## 6. 备份与恢复

必备份：

```bash
sudo cp /etc/ups-pve/runtime.conf /root/runtime.conf.bak.$(date +%s)
sudo cp /opt/ups-manager/TimeCfg.conf /root/TimeCfg.conf.bak.$(date +%s)
sudo cp /etc/nut/upsd.users /root/upsd.users.bak.$(date +%s)
sudo cp /var/lib/ups-pve/battery.json /root/battery.json.bak.$(date +%s)
```

恢复后：

```bash
sudo systemctl restart ups-poller ups-nut-bridge nut-server
```

- [ ] 钉钉 `--test` 成功（不泄露 token）
- [ ] `ups-selftest-watch` 能正常取消一次短自检
